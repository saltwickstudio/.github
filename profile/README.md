# Saltwick Studio

A small independent games studio in Sheffield, run by me, [James Dodd](https://jamesdodd.com).

I'm making **The Tales of Saltwick Isles**, a cosy adventure with optional combat, built in Godot. Along the way I build tools to help with that, and I share the useful ones here.

## Godot addons

| Addon | What it does |
| --- | --- |
| [kaykit-palette-adjust](https://github.com/saltwickstudio/kaykit-palette-adjust) | Recolour single swatches on palette-textured models like the KayKit packs: hue, saturation, brightness, metallic, emission and more, per swatch. |

## About me

I first made games at university back in 2002, then spent years building web games at creative agencies: endless runners, quick-fire microgames, and games for health, education and awareness campaigns. Alongside that I've spent 15+ years in photography, video, design and digital products, working with the BBC, the NHS and the University of Sheffield among others. Saltwick Studio is where it all comes back to games.
